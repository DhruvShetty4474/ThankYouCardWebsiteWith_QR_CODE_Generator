# Logo Setup Instructions

## Divine Mercy Church Logo

To complete the thank you card setup, you need to add the Divine Mercy Church logo to your project:

### Steps:

1. **Save the logo image** as `logo.jpg` in the `public` folder
2. **Ensure the image** is a JPG file with good quality
3. **Optimal size**: Around 200x200 pixels or higher resolution

### File Location:
```
public/logo.jpg
```

### What the logo will do:
- Appears in the top-right corner of the thank you card
- Displays in a circular white container with a blue border
- Responsive sizing for mobile devices
- Professional appearance with shadow effects

### After adding the logo:
1. Commit and push the changes to GitHub
2. Vercel will automatically redeploy
3. Your thank you cards will show the church logo!

### Current Thank You Card Features:
- ✅ Church logo in top-right corner
- ✅ Cycling-themed emojis (🚴‍♂️ and 🏆)
- ✅ Cycling event-specific thank you message
- ✅ Personalized with user's name
- ✅ Animated elements (bouncing bike, pulsing trophy)
- ✅ QR code generation for sharing
